# Diseña tu próximo paso

## Descripción
Web de tres páginas para comparar tres grados universitarios reales: Informática y ADE en la Universidade da Coruña, y Medicina en la Universidade de Santiago de Compostela. Incluye una portada con tarjetas, una tabla comparativa y una página de salidas profesionales con conclusión. Práctica 01 de TIC II, 2.º Bachillerato, curso 2026–2027.

## Tecnologías
- HTML5 y CSS propio (css/estilos.css)
- Bootstrap 5.3.8 cargado por CDN (jsDelivr), por lo que necesita internet
- Git y GitHub
